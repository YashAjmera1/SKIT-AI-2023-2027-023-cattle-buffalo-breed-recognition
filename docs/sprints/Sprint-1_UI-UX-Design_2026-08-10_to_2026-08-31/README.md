## Work done
- Designed complete Figma wireframe system for the Image-Based Indian Cattle & Buffalo Breed Recognition System.
- Defined color system adhering to agricultural and livestock heritage (Forest Emerald `#059669`, Earth Amber `#D97706`, Slate Neutral `#0F172A`).
- Structured dual-panel workspace layout:
  1. **Upload & Configuration Panel**: Category toggle (Cattle 🐄 / Buffalo 🐃), drag-and-drop dropzone with validation states, and instant preview.
  2. **Recognition Results Panel**: Prediction status, top breed identification card, confidence score progress meter, top-3 candidates, and detailed breed profile (origin, milk yield, primary use).
- Prepared responsive design specifications for mobile, tablet, and desktop views.
- Aligned UI layout with UN Sustainable Development Goal 2 (Zero Hunger) and livestock management requirements.
